# Installation

## Stable release

To install Cloudy Forecast, run this command in your terminal:

```sh
uv add fue
```

Or if you prefer to use `pip`:

```sh
pip install fue
```

## From source

The source files for Cloudy Forecast can be downloaded from the [Github repo](https://github.com/sebastian-linden/fue).

You can either clone the public repository:

```sh
git clone https://github.com/sebastian-linden/fue
```

Or download the [tarball](https://github.com/sebastian-linden/fue/tarball/main):

```sh
curl -OJL https://github.com/sebastian-linden/fue/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd fue
uv sync
```
