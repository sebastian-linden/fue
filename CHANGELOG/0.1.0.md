## pyfue 0.1.0 (Initial Release)

Want to know if a weather forecast is reliable? The `pyfue` (Forecast Uncertainty Estimation) Python package quantifies forecast accuracy by training ML models to predict the absolute error of numerical weather predictions. By analyzing historical performance across custom city sets, it turns abstract forecasts into actionable confidence levels for planning your next trip.

This initial release establishes the project scaffold and delivers the core end-to-end machine learning pipeline for uncertainty-aware forecasting.

```sh
pip install pyfue
```

### Infrastructure & scaffold

- Packaging and tooling: the `src/pyfue/` package, a `py.typed` marker, and a `justfile` with development commands such as `qa`, `test`, `type-check`, `docs-serve`, and `release`
- Quality and automation: pytest-based tests, coverage reporting, GitHub Actions CI, Ruff linting, `ty` type checks, CodeQL analysis, and Dependabot updates
- Documentation and release: a Sphinx documentation site using the `sphinx-rtd-theme`, auto-deployed to GitHub Pages, with trusted publishing to PyPI using OIDC and build provenance attestation
- Project hygiene: issue templates, PR template, contributing guide, code of conduct, security policy, MIT license, `.editorconfig`, and `.gitignore`

Built with [Cookiecutter PyPackage](https://github.com/audreyfeldroy/cookiecutter-pypackage).

### Machine learning pipeline engineering achievements

- Automated multi-city data ingestion through an `OpenMeteoClient` and terminal-driven download workflows for assembling forecast and observation datasets
- A custom chronological multi-city data splitting engine designed to prevent temporal and geographic leakage when creating train and evaluation sets
- An extensible abstract base class framework for stateful multi-output and multi-target regression pipelines that can host diverse model implementations
- Core package estimators implemented in the release: `LinearUncertaintyModel`, a multi-output linear regression model built on scikit-learn's `LinearRegression`, and `MLUncertaintyModel`, an ensemble-style MLP-based uncertainty model
- Stateful preprocessing and physical constraints handled by `Preprocessor`, including bounded-target log-transformations and horizon feature mappings such as square-root time deltas
- CLI workflows implemented with Typer, including `download` and `dataset-summary` commands wrapped in explicit structural group callbacks
- Forecast visualization layers with custom weather-semantic color palettes built from Matplotlib for clearer interpretation of uncertainty outputs
